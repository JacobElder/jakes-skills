Before writing anything up, I need to flag a critical methodological problem with this analysis — one that makes the current results unreportable as-is.

## The problem: treating 5,000 observations as independent

Your data are **100 participants × 50 trials each**. The 50 trials within each person are not independent — they share that person's baseline accuracy, processing style, and responsiveness to condition. Running `lm()` on the full trial-level dataset treats all 5,000 rows as if they came from 5,000 different people. This has two serious consequences:

**1. Severely anti-conservative standard errors.** The model borrows degrees of freedom it doesn't have. For any effect that varies within participants (almost certainly `condition`), the test statistic is computed against the wrong error term. The effective *N* for testing participant-level predictors like `age` is 100, not 5,000.

**2. Your p = 0.008 interaction may be a false positive.** Inflation of Type I error from ignoring clustering is not subtle — in within-subjects experiments with ~50 trials per person, false-positive rates for `lm()` on trial-level data routinely run 3–5× the nominal rate. A result that looks like p = 0.008 could easily be p > 0.05 under the correct model.

The N = 5,000 power argument works only for power *within* a properly specified model. You can't claim that power from 5,000 observations when the model's standard errors are biased.

## What the correct model looks like

A few things I need to clarify to nail the spec — I'll make the most common assumption and flag where alternatives apply.

**Assuming `condition` varies within participants** (each person did trials under multiple conditions), the minimal correct model is:

```r
library(lme4)
library(lmerTest)

m <- lmer(accuracy ~ condition * age + (1 + condition | participant),
          data = d,
          REML = TRUE)
summary(m)
```

Here's what each part does and why it's required:

| Component | Why it's there |
|---|---|
| `(1 \| participant)` | Random intercept — people differ in baseline accuracy |
| `(condition \| participant)` | **Random slope for condition** — people differ in how much `condition` affects them. Omitting this uses the wrong error term for the condition effect and the condition × age interaction |
| `condition * age` | Expands to `condition + age + condition:age` |

**If accuracy is binary (0/1)**, use `glmer(..., family = binomial)` instead of `lmer`. Binary outcomes with `lm()` compound the clustering problem with a distributional violation.

**If `condition` is between-subjects** (each person is in only one condition), then no random slope for condition is possible, and the correct model is `(1 | participant)` — but then `condition` and `age` are both level-2 predictors and your effective N is 100. Still requires MLM.
