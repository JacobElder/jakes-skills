## 2. Data preparation

```r
# Assume your data frame is `df` with 21 columns (one per item)
# Items should be numeric 0–4, no row-level sum scores

# Quick check
dim(df)           # should be 412 × 21
sapply(df, range) # all should be 0–4
sum(is.na(df))    # inspect missingness

# Optional: meaningful column names help enormously in plots
colnames(df) <- c(
  "Anhedonia", "DepMood", "Sleep", "Fatigue", "Appetite",
  "Guilt", "Concentration", "Psychomot", "Suicidality",   # PHQ-9
  "Item10", "Item11", "Item12", "Item13", "Item14",        # your 12 extra
  "Item15", "Item16", "Item17", "Item18", "Item19",
  "Item20", "Item21"
)

# Handle missingness — FIML isn't available in qgraph/bootnet directly,
# so either listwise-delete (if minimal) or use a polychoric approach
df_complete <- na.omit(df)   # or use mice for imputation
```

---

## 3. Estimating the network — EBICglasso

The standard for cross-sectional ordinal/Likert symptom data is the **EBIC-regularized Gaussian graphical model (EBICglasso)**. It estimates partial correlations and uses regularization (LASSO + EBIC) to shrink spurious edges to zero.

```r
# Estimate the network
net <- estimateNetwork(
  df_complete,
  default    = "EBICglasso",  # regularized partial correlations
  tuning     = 0.5,           # EBIC hyperparameter γ (0.5 is standard)
  corMethod  = "cor_auto"     # auto-detects ordinal → polychoric correlations
                              # important for 0–4 Likert items
)

# Inspect the edge weight matrix
net$graph   # 21×21 partial correlation matrix (regularized)
```

**Why `cor_auto`?** Your items are ordered categorical (0–4), not continuous. `cor_auto` uses polychoric correlations as input to the GLASSO, which is more appropriate than Pearson.

**Why γ = 0.5?** The conventional default. Lower values (e.g., 0.25) yield denser networks; higher values yield sparser ones. You can explore sensitivity.

## 4. Visualizing the network

```r
# Basic plot — qgraph uses the Fruchterman-Reingold layout by default
plot(net,
     layout    = "spring",
     vsize     = 6,
     label.cex = 0.8,
     legend    = FALSE)

# More controlled version
qgraph(net$graph,
       layout       = "spring",
       vsize        = 7,
       esize        = 10,         # max edge width
       cut          = 0,          # show all edges ≠ 0
       minimum      = 0.05,       # hide edges weaker than this (optional)
       posCol       = "#2196F3",  # blue = positive edges
       negCol       = "#F44336",  # red = negative edges
       labels       = colnames(df_complete),
       label.cex    = 0.7,
       title        = "Depression Symptom Network (EBICglasso)")
```

**Color convention:** Blue edges = positive partial correlations (symptoms co-occur); red edges = negative partial correlations (rare in depression networks, but possible).

## 5. Centrality indices

Centrality tells you which nodes are most "influential" in the network.

```r
# Compute centrality (strength, betweenness, closeness)
centralityPlot(net,
               include = c("Strength", "Betweenness", "Closeness"),
               orderBy = "Strength")

# Get the raw values
cent <- centrality(net)
cent$OutDegree   # "Strength" for undirected = sum of absolute edge weights
cent$Betweenness
cent$Closeness

# Expected Influence (handles negative edges better than Strength)
centralityPlot(net, include = "ExpectedInfluence", orderBy = "ExpectedInfluence")
```

**Which to prioritize?**
- **Strength** (sum of |edge weights|) — most reliable, report this first
- **Expected Influence** — use instead of Strength if you have negative edges
- **Betweenness / Closeness** — less stable (see Section 6); interpret cautiously

## 6. Bootstrap stability analysis

This is **non-negotiable for publication**. You need to show (a) edge weights are estimated accurately, and (b) centrality indices are stable.

### 6a. Edge accuracy (nonparametric bootstrap)

```r
# ~1000 bootstraps; increase for publication
boot_edge <- bootnet(net,
                     nBoots   = 1000,
                     nCores   = 4,     # parallel
                     type     = "nonparametric")

# Plot bootstrapped CIs around edge weights
plot(boot_edge, labels = FALSE, order = "sample")

# Significant edge difference test (are edges statistically distinguishable?)
plot(boot_edge, "edge", plot = "difference",
     onlyNonZero = TRUE, order = "sample")
```

### 6b. Centrality stability (case-dropping bootstrap)

```r
boot_case <- bootnet(net,
                     nBoots             = 1000,
                     nCores             = 4,
                     type               = "case",
                     statistics         = c("Strength", "Betweenness",
                                            "Closeness", "ExpectedInfluence"))

# CS-coefficient: should be ≥ 0.25 (acceptable), ≥ 0.50 (good)
corStability(boot_case)

# Visual
plot(boot_case, statistics = c("Strength", "Betweenness", "Closeness"))
```

**Interpret the CS-coefficient:** If `Strength` CS ≥ 0.50, you can confidently interpret and rank nodes by strength. If `Betweenness` CS < 0.25, do not interpret betweenness rankings.

## 7. Communities / bridge symptoms (optional but useful)

If your 21 items span theoretically distinct symptom clusters (e.g., somatic vs. cognitive), you can examine bridge centrality.

```r
# Define communities manually based on theory
communities <- list(
  PHQ9     = 1:9,       # original PHQ-9 items
  Extended = 10:21      # your 12 additional items
)

# Bridge centrality
bridge_cent <- bridge(net$graph, communities = communities)
plot(bridge_cent, include = "Bridge Strength", order = "value")
```

## 8. Sensitivity checks

```r
# 1. Try γ = 0.25 (less sparse) and γ = 1.0 (more sparse)
net_dense  <- estimateNetwork(df_complete, default = "EBICglasso",
                               tuning = 0.25, corMethod = "cor_auto")
net_sparse <- estimateNetwork(df_complete, default = "EBICglasso",
                               tuning = 1.0,  corMethod = "cor_auto")

# Compare edge counts
sum(net$graph       != 0) / 2
sum(net_dense$graph != 0) / 2
sum(net_sparse$graph!= 0) / 2

# 2. Check if core findings replicate with PCOR (unregularized) for comparison
net_pcor <- estimateNetwork(df_complete, default = "pcor",
                             corMethod = "cor_auto")
```

## 9. What to report

| Element | What to include |
|---|---|
| **Network estimation** | EBICglasso, γ = 0.5, polychoric correlations via `cor_auto` |
| **Network plot** | Edge thickness = weight magnitude, color = sign |
| **Centrality** | Strength (and EI if negative edges present); CS-coefficient |
| **Edge accuracy** | Bootstrapped CIs plot, significant difference plot |
| **Stability** | CS-coefficients for each centrality index |
| **Density** | Proportion of non-zero edges out of possible 21×20/2 = 210 |

## Key gotchas

- **Listwise deletion vs. FIML:** `bootnet` doesn't support FIML natively. If missingness > 5%, consider imputing with `mice` before passing to `estimateNetwork`.
- **Polychoric vs. Pearson:** Always use `cor_auto` for Likert data — Pearson underestimates correlations between ordinal items.
- **Centrality ≠ causality:** Network edges are *associations*, not causal paths. Avoid "symptom X causes symptom Y" language unless you have longitudinal/ESM data.
- **Sample size:** 412 is adequate for a 21-node network, though on the lower end for stable betweenness/closeness estimates — lean on Strength.
