Great question — and a timely one, since reviewer expectations for network papers have crystallized substantially around a handful of landmark methodological papers. Here's what current standards call for, organized by section.

---

## Methods Section

### 1. Node Selection & Rationale
- Explicitly justify **why these 12 symptoms were chosen** (theory-driven, scale-based, or exhaustive). Reviewers increasingly flag atheoretical node selection.
- Note whether any items were excluded and why (e.g., redundancy, multicollinearity).

### 2. Correlation Type
- State that you used **polychoric correlations** and explain why (ordinal response scales violate Pearson assumptions; polychoric estimates latent continuous correlations).
- Report the **response scale** (e.g., 0–3 Likert) so the choice is self-evidently justified.

### 3. Network Estimation — EBICglasso
Specify all of the following:
- **Estimator**: EBICglasso (graphical LASSO with EBIC model selection)
- **Hyperparameter**: γ = 0.5 — note this is the conventional default, but briefly justify (higher γ = sparser graph; 0.5 balances sparsity and sensitivity)
- **Regularization purpose**: shrinks small/spurious edges to zero to reduce false positives in small-to-moderate samples
- **Software + version**: typically `qgraph` and/or `bootnet` in R; cite Epskamp et al. (2012) for `qgraph` and Epskamp et al. (2018) for `bootnet`

### 4. Network Description Metrics
- Specify which **centrality indices** you will report: at minimum **strength** (sum of absolute edge weights); optionally closeness and betweenness, but see caveats below
- If reporting bridge centrality (cross-community edges), cite Jones et al. (2019)
- Pre-specify the **layout algorithm** (e.g., Fruchterman-Reingold) for reproducibility

### 5. Stability Analyses ← most commonly missing
This is likely what the previous reviewer flagged. Current standards (Epskamp et al., 2018, *Psychological Methods*) require:

| Analysis | What it tests | Statistic to report |
|---|---|---|
| **Bootstrap edge accuracy** | Confidence of individual edge weights | 95% bootstrap CIs around each edge (n ≥ 1,000 iterations) |
| **Edge weight difference tests** | Whether specific edges differ significantly | Bootstrapped difference distributions |
| **Case-dropping stability** (CS-coefficient) | Stability of centrality order under data loss | CS-coefficient per index |

- Report the **CS-coefficient** for each centrality index; ≥ 0.50 = good stability, ≥ 0.25 = acceptable, < 0.25 = interpret with caution or drop the index

---

## Results Section

### 1. Network Visualization
- Present the graph with **edge thickness ∝ edge weight** and color distinguishing positive (blue) vs. negative (red) edges — standard `qgraph` defaults
- Report the **number of non-zero edges** and **graph density** (edges present / edges possible = edges / [k(k−1)/2])

### 2. Edge Weight Summary
- Provide the **full edge weight matrix** (in-text table or supplementary)
- Report the range and mean of non-zero edge weights
- Identify the **strongest edges** substantively, not just statistically

### 3. Centrality Results
- Report centrality values in a **table** and visualize as a **centrality plot** (standardized z-scores against the mean)
- Flag which indices have CS-coefficients ≥ 0.25 before interpreting them — **do not interpret unstable indices**
- N=340 with 12 nodes: strength is typically stable; closeness and betweenness often are not — state this explicitly

### 4. Stability Results
- Report the **CS-coefficient for each centrality index** and interpret stability thresholds
- Show the **bootstrap CI plot** for edge weights (often as a figure)
- Report whether any specific edge weight comparisons are significant (relevant if you make ordinal claims like "edge A is stronger than edge B")

### 5. Descriptive Statistics
- Include **means, SDs, and pairwise correlations** (or the polychoric correlation matrix) — either in-text or supplementary

---

## Common Gaps That Attract Reviewer Criticism

| Gap | Fix |
|---|---|
| No stability analyses | Add bootnet case-dropping + bootstrap CIs |
| Interpreting betweenness/closeness without checking CS-coefficient | Report CS first; caveat or drop unstable indices |
| Claiming γ = 0.5 is "optimal" | Say it's the conventional default; consider a sensitivity check with γ = 0.25 |
| No edge weight table | Add as supplementary |
| Comparing edge weights without difference tests | Run and report bootstrapped difference tests |
| No density statistic | Trivial to add, expected |

## Key References to Cite

1. **Epskamp, S., & Fried, E. I. (2018).** A tutorial on regularized partial correlation networks. *Psychological Methods, 23*(4), 617–634. — the canonical methods reference
2. **Epskamp, S., Borsboom, D., & Fried, E. I. (2018).** Estimating psychological networks and their accuracy: A tutorial paper. *Behavior Research Methods, 50*, 195–212. — the stability/bootnet reference
3. **Epskamp, S., Cramer, A. O. J., et al. (2012).** qgraph. *Journal of Statistical Software.* — software citation
4. **Fried, E. I., et al. (2016).** Measuring depression over time… — model for the symptom network write-up style
