## Betweenness Centrality

**Betweenness centrality** measures how often a node lies on the *shortest path* between other pairs of nodes in a network. It captures how much a node acts as a **bridge or bottleneck** for information (or flow) moving through the network.

### The Formula (conceptually)

For a node *v*:

> BC(v) = Σ (shortest paths between s and t that pass through v) / (total shortest paths between s and t)

...summed over all pairs of nodes *s* and *t*.

A node with **high betweenness** sits on many shortest paths — remove it, and many connections become longer or break entirely.

---

### Simple Example

Consider this network:

```
A — B — C — D — E
        |
        F — G
```

Node **C** has high betweenness centrality because:
- Every path from {A, B} to {D, E, F, G} runs through C
- It's the single connector between two clusters

If C is removed, the network splits into two disconnected parts.

---

### When Is It Useful?

| Domain | Use Case |
|---|---|
| **Infrastructure** | Identifying which routers/roads, if disrupted, would most cripple a network |
| **Social networks** | Finding "broker" individuals who connect otherwise separate social groups |
| **Biology** | Pinpointing proteins whose removal would disrupt cellular signaling pathways |
| **Supply chains** | Spotting single-points-of-failure — suppliers everything routes through |
| **Epidemiology** | Targeting high-betweenness individuals for vaccination to slow disease spread |

---

### Key Distinction from Other Centrality Measures

| Measure | What it captures |
|---|---|
| **Degree centrality** | How many direct connections a node has |
| **Closeness centrality** | How quickly a node can reach all others |
| **Betweenness centrality** | How much a node *controls flow* between others |

A node can have **low degree but high betweenness** — think of a small town that happens to sit at a highway junction between two major cities. It's not the biggest place, but everything passes through it.
