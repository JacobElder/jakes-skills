---

## The overlapping-CI fallacy

Overlapping individual CIs **do not** imply non-significance of the difference. This is one of the most common misinterpretations in applied statistics.

**Why the logic fails mathematically.** A 95% CI for a single estimate addresses: *does this value differ from zero?* It says nothing direct about whether *two values differ from each other*. To test the difference, you need a CI for the quantity (A − B), not for A and B separately.

For two independent, roughly normal estimates:
- Individual 95% CIs just barely overlapping corresponds to roughly **p ≈ .01** for the difference — highly significant.
- Individual 95% CIs overlapping by up to ~**half a standard error** still corresponds to roughly **p ≈ .05**.
- Individual CIs must overlap by a substantial margin before the difference becomes non-significant.

The rule of thumb "overlapping 95% CIs → non-significant difference" is only true for **~83% CIs**, not 95% CIs.

In your case: A = 0.42 [0.18, 0.61], B = 0.39 [0.17, 0.58]. The intervals overlap extensively — but that's consistent with neither estimate being far from zero. It tells you almost nothing about whether 0.42 vs. 0.39 is a real difference.

---

## The correct test: bootstrapped difference distribution

The right procedure — described in detail in **Epskamp, Borsboom & Fried (2018)** for psychological networks — is:

1. For each bootstrap sample *b*, compute Strength(A)_b − Strength(B)_b.
2. Build the empirical distribution of those *B* difference scores.
3. The 95% CI of **that difference distribution** is what you report. If it excludes zero, the difference is significant.

This is what the `bootnet` package implements directly.

---

## Concrete R workflow (bootnet)

```r
library(bootnet)

# Estimate your network (example with EBICglasso)
net <- estimateNetwork(data, default = "EBICglasso")

# Run non-parametric bootstrap (nBoots ≥ 1000 recommended)
boot <- bootnet(net, nBoots = 1000, type = "nonparametric")

# Visual test: nodes whose CIs do NOT overlap differ significantly
plot(boot, "strength", order = "sample", labels = TRUE)

# Formal difference test for node A vs node B
differenceTest(boot, x = "A", y = "B", measure = "strength")
```

`differenceTest()` returns the bootstrapped CI for (Strength_A − Strength_B) directly. Check whether that CI includes zero.

The visual plot of the difference matrix is equally informative: a cell is colored when the bootstrapped CI for that pair's difference excludes zero.
