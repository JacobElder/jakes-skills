## Methods Section — Required Elements

State your full software environment. Reviewers will check this. Minimally:

- R version
- `qgraph` (network estimation & visualization)
- `bootnet` (accuracy and stability)
- `igraph` (if used for community detection)
- `psychotools` or `psych` (if used for polychoric estimation)

Example phrasing:
> *"All analyses were conducted in R (v4.3.x) using the qgraph (v1.9.x), bootnet (v1.5.x), and igraph (v1.5.x) packages."*

## Results Section — Required Elements

### 1. Network Description
- Number of nodes (*k* = 12) and estimated edges
- **Network density** (proportion of possible edges that are non-zero): `(# non-zero edges) / (k(k−1)/2)`
- Range and mean of non-zero edge weights
- Whether the network is entirely positive-edge or contains negative edges (negative edges get special interpretive attention)

---

### 2. Network Visualization
- Figure with labeled nodes, edge widths proportional to |partial correlation|, positive edges in one color (green), negative in another (red)
- State the layout algorithm (typically Fruchterman-Reingold / spring layout via `qgraph`)
- Include a full edge weight matrix — typically as a supplementary table, but reviewers expect it to exist

---

### 3. Centrality Indices — Report Selectively and Justify
This is where many papers get criticized. Current standards (post-2019) say:

**Report:**
- **Strength** (sum of absolute edge weights) — most stable, most interpretable
- **Expected Influence** (signed sum of edge weights) — preferred if negative edges are present, as it preserves sign information

**Be cautious with:**
- **Betweenness** and **Closeness** — these are now routinely flagged by reviewers because they are empirically unstable in small-to-medium samples and may not have clear psychological interpretations. If you include them, cite evidence of their stability from your bootstrap analysis. Many papers now omit them or relegate them to supplements.

**Cite the instability concern:**
> Epskamp, S., Haslbeck, J. M. B., Isvoranu, A. M., & van Borkulo, C. D. (2022). Psychological network analysis. In *Methodology in the Social Sciences.*

Present centrality as a **standardized bar plot** (the standard `qgraph` output), not just tables.

---

### 4. Stability Analyses — The Section Most Often Missing or Inadequate

This is almost certainly what your reviewer was flagging. You need all three of these:

#### A. Edge Weight Accuracy (Nonparametric Bootstrap CIs)
- Run `bootnet(..., nBoots = 1000, type = "nonparametric")`
- Plot bootstrapped 95% CIs around each edge weight
- Narrow CIs around large edges = good accuracy
- Report: *"Bootstrapped confidence intervals for edge weights indicated that [X] edges were estimated with good accuracy, as reflected by narrow CIs."*

#### B. Edge Weight Difference Tests
- Using the same bootstrap object, test whether edge weights are significantly different from zero and from each other
- Plot the edge difference matrix (red = different, grey = not)
- This tells readers which edge weight comparisons are reliable

#### C. Centrality Stability (CS-Coefficient)
- Run `bootnet(..., nBoots = 1000, type = "case")`
- Calculate the **CS-coefficient** for each centrality index via `corStability()`
- **Minimum acceptable threshold: CS ≥ 0.25**
- **Preferred threshold: CS ≥ 0.50**
- If Betweenness/Closeness have CS < 0.25, you should not interpret them — drop them or relegate to a note

Report like:
> *"The CS-coefficient for strength was 0.67, indicating robust stability. Betweenness demonstrated poor stability (CS = 0.18) and is not interpreted further."*

---

### 5. Predictability (Optional but Increasingly Expected)
Haslbeck & Fried (2017) introduced **node predictability** (R² analog): the proportion of each node's variance explained by its neighbors. This is increasingly expected in psychopathology networks:

> Haslbeck, J. M. B., & Fried, E. I. (2017). How predictable are symptoms in psychopathological networks? *European Journal of Psychopathology, 28*(2), 1–8.

Computed via the `mgm` package. Report as a pie chart overlay on the network plot.

## Common Gaps That Draw Reviewer Criticism

| Gap | Fix |
|---|---|
| No bootstrap stability reported | Run `bootnet` case-dropping bootstrap; report CS-coefficients |
| Betweenness/closeness interpreted without stability checks | Drop or caveat with CS-coefficient |
| No edge weight CIs | Run nonparametric bootstrap; plot CIs |
| Gamma not reported | State γ = 0.5 explicitly |
| No justification for polychoric | One sentence: ordinal data → polychoric recovers latent normal distribution |
| Edge weight matrix absent | Add as supplementary table |
| Package versions missing | Add to Methods |
| Density not reported | Calculate and report |
| No difference tests | Run `differenceTest()` in bootnet; include plot |

---

## Reproducibility Expectations

Top journals now expect:
- Full analysis code (OSF or GitHub)
- Either raw data or the correlation/partial correlation matrix
- A statement in the paper pointing to the repository
