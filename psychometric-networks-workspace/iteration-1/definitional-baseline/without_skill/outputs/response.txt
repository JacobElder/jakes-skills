## Psychometric Networks vs. Factor Models

Both approaches model the *covariance structure* among a set of items or variables, but they make fundamentally different assumptions about *why* those items covary.

---

### Factor Models: Common Cause Logic

A factor model (CFA, EFA, IRT) assumes that observed correlations among items are **entirely explained by one or more latent variables** — unobserved common causes that "drive" item responses.

```
F
├──→ Item 1
├──→ Item 2
└──→ Item 3
```

- Items correlate *only because* they share a common cause (local independence assumption)
- Remove the factor, and items become conditionally independent
- The latent variable is treated as **real** — it causes the responses
- Residuals are assumed uncorrelated (or modeled carefully if not)

**Classic use:** Big Five personality, IQ, depression scales — anywhere you believe a unifying construct drives responses.

---

### Psychometric Networks: Mutual Reinforcement Logic

A network model (typically a **Gaussian Graphical Model**, or GGM) treats items as **directly interacting nodes** connected by edges representing *partial correlations* — the association between two items after conditioning on all other items in the system.

```
Item 1 ——— Item 2
  \           |
   \          |
    Item 3 ——'
```

- There is **no latent variable** — items covary because they causally or functionally influence each other
- Edges = partial correlations (in a GGM), estimated via regularized regression (e.g., LASSO/glasso)
- The correlation structure *emerges* from the network topology
- **Centrality metrics** (strength, betweenness, closeness) describe each node's role in the system

**Classic use:** Comorbidity of symptoms (e.g., depression-insomnia-fatigue as a mutually reinforcing cluster), where no single latent disease "causes" everything.

---

### Key Conceptual Differences

| Dimension | Factor Model | Network Model |
|---|---|---|
| **Causal story** | Latent variable → items | Items ↔ items (mutual influence) |
| **Core assumption** | Local independence | No assumed independence |
| **Main parameter** | Factor loadings | Partial correlations (edges) |
| **Latent entity** | Yes — the factor | No — emergent structure |
| **Key output** | Factor scores, loadings | Edge weights, centrality |
| **Fits when** | Reflective constructs | Formative / symptom networks |

---

### The Deep Tension

Here's the tricky part: **the two models can fit the same data equally well.** A one-factor model and a network model can be statistically equivalent representations of the same covariance matrix. This is the *factor-network duality* (Golino & Epskamp, 2017; Kruis & Maris, 2016).

The difference is **theoretical**, not always empirical:
- Do you believe *depression* is a latent entity that causes sadness, fatigue, and insomnia? → Factor model
- Do you believe sadness causes poor sleep, which causes fatigue, which worsens mood? → Network model

This is why network psychometrics is sometimes criticized as *redescription* rather than discovery — and why the debate is genuinely unresolved for many constructs.

---

### When Networks Add Unique Value

Networks earn their keep when:
1. **Bridge symptoms** matter — identifying which nodes connect two clusters (e.g., linking anxiety and depression networks)
2. **Treatment targeting** — high-centrality nodes may be leverage points for intervention
3. **Heterogeneous item sets** — where a single latent factor clearly doesn't fit
4. **Longitudinal/idiographic networks** — modeling within-person dynamics (e.g., experience sampling data)

The *qgraph* and *bootnet* packages in R are the standard toolkit; the *EGAnet* package extends this to exploratory graph analysis for dimensionality assessment.
