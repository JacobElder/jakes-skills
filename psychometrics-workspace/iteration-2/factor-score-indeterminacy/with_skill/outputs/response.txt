Not quite — and the issue is subtle enough that it trips up a lot of applied researchers.

The workflow you're describing (run EFA with psych::fa(), extract fa()$scores, plug into regression) is common, but it glosses over a fundamental problem with EFA factor scores: **factor score indeterminacy**.

## The indeterminacy problem

In EFA, factor scores are not uniquely determined by the model and data. For any given factor solution — the same loadings, the same observed covariance matrix — there are infinitely many sets of factor scores that are mathematically consistent with the model. The scores fa()$scores gives you (Thurstone regression scores by default) are one particular solution from that infinite family. Another researcher using the same data and the same factor solution could produce a completely different set of scores that fit the model just as well.

This is not a rounding issue or a sampling artifact. It's a logical consequence of the common factor model: the factors are latent (unobserved), and the observed items underdetermine them. Grice (2001, *Applied Psychological Measurement*) is the modern reference if you need to document this.

The indeterminacy is smaller when factor loadings are strong and communalities are high, and larger when loadings are weak. But it never goes to zero in EFA.

## Why this matters for regression

When you use fa()$scores as predictors in regression, you're treating one arbitrary element of an infinite set of equivalent solutions as if it were the "true" factor score. Your regression coefficients and their interpretation are contingent on that arbitrary choice. Replicators using a different scoring algorithm or a slightly different rotation will get different predictors and different regression results — not because the analysis is wrong, but because factor scores in EFA are fundamentally ambiguous.

## What to do instead

**Option 1 (usually the right call): Unit-weighted composite scores**

Sum the items with salient loadings on each factor (with reverse-coding where needed). This is transparent, reproducible, and surprisingly competitive with estimated factor scores in practice:

```r
# Example: items 1, 3, 5 load on Factor 1; items 2, 4, 6 load on Factor 2
factor1_score <- rowMeans(data[, c("item1", "item3", "item5")])
factor2_score <- rowMeans(data[, c("item2", "item4", "item6")])
```

Sum scores have a unique mathematical definition (anyone can reproduce them), don't require the factor model at all, and behave well in downstream regression.

**Option 2: Move to CFA if you have a defensible structure**

CFA in lavaan, combined with full-information estimation or Bartlett/regression factor scores from a *specified* (constrained) model, produces factor scores that are better-defined than EFA scores because the model imposes additional constraints that reduce indeterminacy. If your EFA produced a clean, interpretable structure you're willing to commit to, fit that structure as a CFA:

```r
library(lavaan)
model <- '
  F1 =~ item1 + item3 + item5
  F2 =~ item2 + item4 + item6
'
fit <- cfa(model, data = data, estimator = "MLR")
scores <- lavPredict(fit)  # latent variable scores from CFA
```

CFA scores are still estimates (not perfectly determined), but the additional model constraints sharply reduce indeterminacy compared to EFA.

**Option 3: SEM directly**

If your ultimate goal is a regression of some outcome on the latent factors, skip factor scores entirely and model the full system as a structural equation model. You avoid the two-step problem (measurement error in factor scores propagating into regression) and get correct standard errors.

## Bottom line

fa()$scores is not "wrong" in a computational sense — it does what the documentation says. The problem is interpreting those scores as if they are the unique, true latent factor scores. They aren't: EFA factor score indeterminacy means there's no uniquely correct set of scores, and the ones you extract are one arbitrary choice. For downstream regression, unit-weighted composites are more defensible and more reproducible. CFA or SEM are better still if you're willing to commit to a structure.
