Here's a sensible default approach for running EFA on 25 Likert items in R using the `psych` package.

## Step 1: Determine the number of factors with parallel analysis

Before calling `fa()`, use `fa.parallel()` to get an empirical estimate of how many factors to extract:

```r
library(psych)

# Use polychoric correlations since these are Likert items
fa.parallel(your_data, fa = "fa", cor = "poly")
```

Parallel analysis is more reliable than Kaiser's eigenvalue > 1 rule (which tends to overextract). Look at where observed eigenvalues drop below the random-data eigenvalues. Also examine the scree plot. Let k be your candidate number of factors.

## Step 2: Run the EFA

```r
efa_result <- fa(
  your_data,
  nfactors = k,          # from parallel analysis
  fm = "minres",         # minimum residual — good general-purpose extractor
                         # doesn't require multivariate normality
  rotate = "oblimin",    # oblique rotation — allows factors to correlate,
                         # which is realistic for psychological constructs
  cor = "poly"           # polychoric correlations for ordinal Likert items
)

print(efa_result, cut = 0.3, sort = TRUE)
```

## Why these choices?

**`cor = "poly"` — polychoric correlations**

Likert items are ordinal, not continuous. Pearson correlations applied to 5-point scales underestimate the true latent correlations, which biases your loadings downward and can distort factor structure. Polychoric correlations model each item response as a discretization of an underlying continuous variable, and estimate the correlation between the underlying continuous variables. For Likert data, this is the right input matrix for EFA.

**`fm = "minres"` — minimum residual extraction**

Minres (minimum residual) is the default in `psych::fa()` and a solid general-purpose choice. It minimizes the off-diagonal residuals without requiring multivariate normality. It's also less prone to Heywood cases (where a communality estimate exceeds 1) compared to maximum likelihood. If you want a chi-square goodness-of-fit test and SEs, use `fm = "ml"` instead — but ML is more sensitive to non-normality and can be unstable with ordinal data.

**`rotate = "oblimin"` — oblique rotation**

Psychological constructs are almost always correlated. Using varimax or another orthogonal rotation imposes the constraint that your factors are uncorrelated — a constraint that is rarely true and that can distort the loading pattern. Oblique rotations (oblimin, promax) allow factors to correlate and give you a more realistic solution. If your factors turn out to be empirically near-zero correlated, oblique gives essentially the same result as orthogonal. Promax is a popular alternative oblique option.

**Do not use varimax by default** for psychological scale data.

## Examining results

```r
# Pattern matrix — use this for interpretation (not the structure matrix)
efa_result$loadings

# Factor correlations (from oblique rotation)
efa_result$Phi

# Communalities — items < .30 may not be well-captured
efa_result$communalities
```

Report the pattern matrix (standardized regression weights of items on factors) for interpretation. Always report the factor correlation matrix when using oblique rotation.

## Practical notes

- Try k-1, k, and k+1 factors and compare the interpretability of the solutions — the "correct" number of factors is partly a substantive judgment, not purely statistical.
- Check KMO (≥ .60, ideally ≥ .80) and Bartlett's test of sphericity before proceeding.
- With 25 items across k factors, ensure you have adequate sample size. A general guideline: aim for at least 5-10 respondents per item and at least 4 items clearly loading on each factor for a stable solution.
