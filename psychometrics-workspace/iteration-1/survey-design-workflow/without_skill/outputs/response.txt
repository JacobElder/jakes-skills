Great question — designing and validating a new psychometric scale requires a systematic workflow. With 8 Likert items targeting "product trust" and ~600 participants, you're in good shape. Here is a recommended analysis pipeline and key pitfalls to avoid.

---

## STEP 1: Pre-Analysis Quality Checks

Before any factor analysis, inspect your data:
- Check for missing data patterns (MAR vs. MCAR) and decide on listwise deletion vs. imputation
- Look at item-level descriptives (means, SDs, skew, kurtosis)
- Screen for careless responders (e.g., straight-liners, impossibly fast completion times)
- Check for floor/ceiling effects on individual items

---

## STEP 2: Correlation Matrix — Use Polychoric, Not Pearson

Because your items are 7-point Likert scales, they are ordinal, not continuous. Pearson correlations will underestimate the true relationships between items. Instead, use **polychoric correlations**, which model the underlying continuous latent variable.

In R with the `psych` package:

```r
library(psych)

# Compute polychoric correlation matrix
poly_cor <- polychoric(your_data)
poly_matrix <- poly_cor$rho
```

Using Pearson correlations with ordinal data is one of the most common and consequential mistakes in scale development.

---

## STEP 3: Determine Number of Factors — Use Parallel Analysis, NOT Kaiser's Rule

A very common mistake is using the **eigenvalue > 1 rule** (Kaiser criterion) to decide how many factors to retain. This rule has poor accuracy and routinely over-extracts factors. **Do not rely on it.**

Instead, use **parallel analysis**, which compares your observed eigenvalues to eigenvalues from random data matrices of the same size. Retain factors whose observed eigenvalues exceed the simulated 95th-percentile eigenvalues.

```r
library(psych)

# Parallel analysis using polychoric matrix
fa.parallel(poly_matrix, n.obs = 600, fa = "fa", fm = "ml")
```

You can also supplement with the **scree plot** (look for the "elbow") and **Very Simple Structure (VSS)** or **MAP criterion** as additional checks.

---

## STEP 4: Exploratory Factor Analysis (EFA)

Run EFA on roughly half your sample (randomly split). With 600 participants, a 300/300 split gives you enough power for both EFA and CFA.

Key decisions:
- **Estimation method**: Use Maximum Likelihood (ML) if data are approximately normal, or Weighted Least Squares (WLS/WLSMV) for ordinal data
- **Rotation**: Use an **oblique rotation** (e.g., `oblimin` or `promax`) rather than orthogonal Varimax. Oblique rotations allow factors to correlate, which is almost always more realistic in psychological measurement. Forcing orthogonality (Varimax) when factors are actually correlated distorts your solution.

```r
# EFA on first half of sample using polychoric matrix
efa_result <- fa(r = poly_matrix,
                 nfactors = 1,   # adjust based on parallel analysis
                 rotate = "oblimin",
                 fm = "ml",
                 n.obs = 300)

print(efa_result, cut = 0.3, sort = TRUE)
```

Examine:
- Factor loadings (ideally > 0.40)
- Cross-loadings (ideally < 0.30)
- Communalities (ideally > 0.30)
- Model fit indices (RMSEA, CFI, SRMR) if using ML extraction

---

## STEP 5: Reliability — Use Omega, Not Just Alpha

Coefficient alpha (Cronbach's alpha) is ubiquitous but problematic. It assumes tau-equivalence (all items load equally on the factor), which is almost never true. When this assumption is violated, alpha underestimates reliability.

**McDonald's omega (ω)** is a better reliability estimate because it accounts for differential factor loadings. Report both omega-total (ωt) and omega-hierarchical (ωh) when relevant.

```r
# Omega reliability
omega_result <- omega(your_data, nfactors = 1)
print(omega_result)
```

Reporting only alpha is increasingly criticized in the psychometrics literature. If alpha is the only reliability estimate you report, reviewers may push back.

---

## STEP 6: Confirm with CFA on the Held-Out Sample

After EFA on your first subsample, test the resulting structure using **Confirmatory Factor Analysis (CFA)** on the second (independent) subsample. This is critical — fitting and testing a model on the same data is circular and inflates fit.

With 600 participants, splitting 300/300 is reasonable. Some researchers use 400/200 if the EFA needs more power.

```r
library(lavaan)

# Define your 1-factor model (adjust based on EFA)
model <- '
  trust =~ item1 + item2 + item3 + item4 + item5 + item6 + item7 + item8
'

# Fit CFA on second half of sample
fit <- cfa(model, data = second_half, estimator = "MLR")
summary(fit, fit.measures = TRUE, standardized = TRUE)
```

For 7-point Likert items, consider using `estimator = "WLSMV"` with ordered = TRUE:

```r
fit_ordinal <- cfa(model, data = second_half,
                   ordered = TRUE,
                   estimator = "WLSMV")
```

Evaluate fit using: CFI > 0.95, RMSEA < 0.06, SRMR < 0.08.

---

## STEP 7: Sample Size — 600 Is Adequate

With 8 items and ~600 participants, your sample is well-powered for both EFA and CFA. General rules of thumb suggest:
- EFA: at least 5-10 participants per item (you have 75:1), or N > 200 minimum
- CFA: N > 200 is the common minimum; 300+ is comfortable for simple models
- Your 300/300 split comfortably supports both stages

That said, adequacy depends on communalities and factor loadings — higher loadings and fewer factors require smaller samples. With a clean single-factor solution (likely for "product trust"), 600 is more than sufficient.

---

## STEP 8: Qualitative / Content Validity Steps

Do not skip the non-statistical steps:
- **Expert review**: Have domain experts (and ideally target users) review items for content validity before data collection
- **Cognitive interviews**: Conduct think-aloud sessions with 5-10 representative users to ensure items are understood as intended
- **Face validity**: Ensure items look like they measure what you claim
- **Pilot testing**: Run a small pilot (20-30 people) to catch issues before the main data collection

These qualitative steps are often treated as an afterthought but are foundational to construct validity. A statistically beautiful factor structure does not compensate for items that were poorly written or misunderstood.

---

## Summary of Key Mistakes to Avoid

| Mistake | Better Approach |
|---|---|
| Pearson correlations on Likert items | Polychoric correlations |
| Eigenvalue > 1 rule for # of factors | Parallel analysis |
| Orthogonal (Varimax) rotation | Oblique rotation (oblimin/promax) |
| Reporting only Cronbach's alpha | Also report McDonald's omega |
| Running EFA and CFA on same sample | Split sample or use independent sample |
| Skipping qualitative validation | Cognitive interviews + expert review |
| Treating 7-point scale as continuous in CFA | Use WLSMV estimator with ordered indicators |
